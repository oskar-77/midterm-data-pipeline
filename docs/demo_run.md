# تقرير التشغيل التجريبي

## نطاق التجربة

تم تشغيل خط البيانات على الملف `data/demo_orders.csv`، وهو ملف افتراضي يضم **8 سجلات** مصممة لتغطية الحالات السليمة والقابلة للتصحيح وغير القابلة للتصحيح. استُخدم محرك `python_batch` بحجم دفعة قدره 3 سجلات، مع `mongomock` لمحاكاة MongoDB محليًا دون الحاجة إلى خادم قاعدة بيانات خارجي.

## أمر التشغيل

```bash
python3 scripts/run_demo.py
```

## الملفات الناتجة

- `data/demo_orders.csv`: البيانات الافتراضية المستخدمة في التجربة.
- `reports/demo_run_results.json`: القياسات التفصيلية بصيغة JSON.
- `scripts/run_demo.py`: سكربت قابل لإعادة تشغيل التجربة باستخدام `mongomock`.

> ملاحظة: التشغيل الكامل عبر `src/main.py` دون الخيار `--dry-run` يتطلب خادم MongoDB فعليًا. أما تجربة هذا التقرير فتعزل الاعتماد الخارجي باستخدام `mongomock`، مع إبقاء منطق التحميل والتنظيف والتصنيف وقياس النتائج نفسه.
